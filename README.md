# 🏆 Local AI Voice Assistant - "Hey Friday"

## 🚀 Overview
This is a **100% offline AI voice assistant** that:
✅ **Listens for "Hey Friday"** before activation  
✅ **Understands & processes speech** using **Whisper**  
✅ **Generates AI responses** using **DeepSeek R1 via Ollama**  
✅ **Speaks back** using **Coqui TTS**  
✅ **Runs completely offline (No API required!)**
